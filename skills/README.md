# Skills

上游來源：[mattpocock/skills](https://github.com/mattpocock/skills)。

本目錄是 Skill 導航，不是上游 Skill 的複本，也不代表已安裝任何工具。使用前檢查當前環境可用 Skill 的實際名稱及說明，避免假設版本或自動載入方式。

| 需求 | 優先選用的工作方式 |
|---|---|
| 釐清不確定需求與設計 | grill-me / grill-with-docs（若已安裝） |
| 記錄已決定的需求 | to-spec 或同等規格 Skill |
| 拆成可獨立驗收的工作 | to-tickets / to-issues 或當前版本對應 Skill |
| 行為導向實作 | tdd |

只在有實際需求時載入對應 Skill。優先引用已核對的上游版本；不複製、重寫或無條件安裝整套 Skills。
