# Home Repo

一般開發的起點與跨專案知識入口。採用 Matt Pocock 的 [Home Repo / AI coding vocabulary](https://github.com/mattpocock/dictionary-of-ai-coding) 概念與 [skills](https://github.com/mattpocock/skills) 工作方式。

## 使用方式

1. 從本 Repo 啟動 Agent，或由目標專案 AGENTS.md 明確指向本 Repo。
2. 閱讀 [AGENTS.md](AGENTS.md)，辨識任務與所需的情境文件。
3. 進入目標專案的獨立 Git repository，閱讀該專案規則並實作。
4. 將專案進度、issues、PR 留在原專案；跨專案且長期有效的知識才更新到此處。

本 Repo 只保存通用方法，不保存特定組織的內部環境、憑證、個人資料或正式資料。受管制或敏感專案應使用獨立的情境 Home Repo，額外載入適用的安全規則。
